# Team handoff

## Required package

- [ ] Native project revision and a clearly identified fallback
- [ ] Approved media or a relinkable media manifest
- [ ] Fonts and plugin inventory with licenses and version notes (never copy restricted installers here)
- [ ] Final and review renders with naming convention
- [ ] `project-manifest.json` completed
- [ ] Notes covering known issues, expressions, color, audio, and version compatibility

## Handoff message

Use this order: status and approval, exact deliverables, source location, host/version tested, render settings, known limitations, next owner, and deadline. Include checksums when required by the production system.

The recipient should be able to open, identify the approved comp, reproduce a review render, and understand what is intentionally not editable.
