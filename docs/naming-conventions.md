# Naming conventions

Names should be searchable, stable, and meaningful outside the creator's machine.

## Pattern

`[TYPE]_[PROJECT]_[SUBJECT]_[REVISION]`

Examples: `MST_ORBIT_LAUNCH_V003`, `TXT_ORBIT_HEADLINE`, `CTRL_GLOBAL`, `PRE_ORBIT_LOGO_V002`.

Use uppercase for structural prefixes, underscores as separators, and zero-padded shot numbers (`010`, `020`). Avoid duplicate layer names, trailing spaces, dates in comp names, and names based only on color or position.

## Prefixes

`MST` master comp, `PRE` precomp, `CTRL` controls, `TXT` text, `GFX` graphics, `MED` media, `FX` effects, `AUD` audio, `CAM` camera, `NULL` null, `REF` reference.
